# Test Case Reviewer

Простой веб-сайт для ревью тест-кейсов с использованием GigaChat.

## Backend

Файл `backend/app.py` предоставляет эндпоинт `/api/review`, который получает отдельный тест-кейс и возвращает результат анализа GigaChat.

Запуск:

```bash
pip install -r requirements.txt
python backend/app.py
```

## Frontend

Статические файлы находятся в каталоге `frontend`. Откройте `index.html` в браузере, чтобы загрузить XML-файл с тест-кейсами и отправить их на ревью. Результаты выводятся по мере готовности, после чего их можно скачать в формате JSON.
